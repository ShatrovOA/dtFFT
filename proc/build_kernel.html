private subroutine build_kernel(dims, kernel_type, base_storage, props, tile_size, block_rows, kernel, neighbor_data)

Returns the kernel instance for a launch configuration that is already known.

Used when a plan is restored from file: nothing is benchmarked, the recorded tile_size and block_rows are looked up directly.
