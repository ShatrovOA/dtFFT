private subroutine prepare_candidates(dims, kernel_type, base_storage, props, ndims, tile_dim, other_dim, fixed_dims, candidates, num_candidates, neighbor_data)

Works out the candidate launch configurations for a kernel and compiles them all.

The candidate set is a pure function of the local dimensions, the element size and the GPU properties. That is what makes a saved launch configuration replayable: the same inputs always regenerate the same set, so the recorded one is always compiled.
