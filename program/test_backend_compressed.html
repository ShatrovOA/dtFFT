Tests all compressed backends on all platforms available in current build.

Every rank owns a NX x ny_local slab and sends NX x cy blocks to all other ranks. Pack kernel compresses each block before it is sent, unpack kernel decompresses received blocks, so the whole pack -> compress -> exchange -> decompress -> unpack chain is covered for every backend, compressor and compression mode available in current build.

On DTFFT_PLATFORM_CUDA buffers live in device memory: reference data is staged through a host buffer and copied to and from the device, exactly as a user of the library would do. Compressors without a device implementation report DTFFT_ERROR_COMPRESSION_CUDA_NOT_SUPPORTED and such cases are reported as skipped.

Note that self communication is never compressed, so nothing is actually compressed on a single rank. Such a run is pointless and is not registered by CTest at all.

Blocks are kept reasonably large: compressed backends abort when compressed data does not fit into the original buffer, and lossless compressors expand blocks of just a few kilobytes.
