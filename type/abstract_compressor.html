  • pure subroutine get_supported_modes_interface(host_modes, cuda_modes, use_tolerance) Prototype

    Returns supported compression modes Arrays are of size 4, corresponding to the order of VALID_COMPRESSION_MODES: 1. DTFFT_COMPRESSION_MODE_LOSSLESS 2. DTFFT_COMPRESSION_MODE_FIXED_RATE 3. DTFFT_COMPRESSION_MODE_FIXED_PRECISION 4. DTFFT_COMPRESSION_MODE_FIXED_ACCURACY

    Arguments

    Type IntentOptional Attributes Name
    logical, intent(out) :: host_modes(4)

    Supported host compression modes
    logical, intent(out) :: cuda_modes(4)

    Supported cuda compression modes
    logical, intent(out) :: use_tolerance

    Should tolerance parameter be used in DTFFT_COMPRESSION_MODE_FIXED_PRECISION mode instead of precision
